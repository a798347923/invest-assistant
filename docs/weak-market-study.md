# 弱市盈利研究：训练集/验证集分离验证（2026-11）

| 项 | 值 |
|---|---|
| 问题 | 弱市（双指数在 MA20 下方）买入的期望收益是负的，当前策略是"弱市不买"；能否改成弱市也能赚钱？强市能否再提？ |
| 数据 | 236 只 A 股（全市场快照抽样，市值≥50 亿、非 ST、排除自选/持仓），2019-01 ～ 2026-10，**前复权**日线 |
| 训练集 | 2023-11-01 ～ 2026-10-31（近 3 年，用于开发方法） |
| 验证集 | 2019-11-01 ～ 2023-10-31（3 年前，**只用于验收**） |
| 引擎 | 复用线上同一份 `engine.playbook_replay._replay_code`（次日开盘成交、机械止损/止盈/超时、0.15%/笔成本） |
| 结论 | **29 个组合无一同时通过训练集与验证集**；最强候选（弱市+指数在 MA60 上方）在验证集最好、在训练集最差，符号翻转 → 线上规则保持不变 |

> 复现：`python scripts/research/data.py --n 240` → `python scripts/research/study.py --set {diagnose,full,reversal,gates}` →
> `python scripts/research/summary.py`。原始结果在 `data/research/study_*.json`。

## 1. 协议

1. **窗口分离**：方法只允许在训练集上挑选与调参；验证集在选定候选之前不看。
2. **采纳门槛**（比用户口径更严，防止"过去赚钱、最近亏钱"的规则上线）：
   - 验证集：期望 > 0、胜率 ≥ 50%、样本 ≥ 40、t ≥ 2；
   - 训练集：期望 ≥ 0（不得在开发窗口亏钱）；
   - 强市子集不得因改进而变差（期望下降 > 0.05pp 或胜率下降 > 1pp 即否决）。
3. **口径一致**：不为研究另写撮合逻辑，直接调用线上回放引擎；样本外只多取 120 天做 MA60 预热，只统计入口落在窗口内的交易。
4. **成本**：佣金 0.025%×2（最低 5 元近似）、印花税 0.05%、滑点 0.1%（含在成交价），合计 0.15%/笔往返。

## 2. 诊断：弱市到底是什么样

| 窗口 | 子集 | 笔数 | 胜率 | 期望 | 中位 | t | 止损率 | 目标率 | 超时率 | 平均持有 |
|---|---|---|---|---|---|---|---|---|---|---|
| 训练集 | 强市（现行） | 2060 | 61.0% | **+1.57%** | +6.04% | 6.32 | 14.3% | 52.6% | 33.1% | 25.1 |
| 训练集 | 弱市（放开） | 1257 | 53.8% | **−0.38%** | +1.68% | −1.14 | 22.3% | 39.9% | 37.8% | 27.1 |
| 验证集 | 强市（现行） | 1976 | 57.7% | **+0.65%** | +4.63% | 2.49 | 18.7% | 46.9% | 34.5% | 27.3 |
| 验证集 | 弱市（放开） | 1796 | 56.3% | **+0.19%** | +3.28% | 0.66 | 18.9% | 44.8% | 36.2% | 26.6 |

三个结论：

1. **弱市不是"负期望"，而是"零期望 + 左尾"**：胜率仍有 54–56%、中位数为正，均值被少数大亏拖到 0 附近；最近 3 年偏负（−0.38%），2019–2023 略正（+0.19%）。所以"弱市不买"更像**风险决策**（弱市回撤 −886 vs 强市 −719），不是收益决策。
2. **弱市里亏损来自止损和超时**：止损率 22.3%（强市 14.3%），超时率 37.8%，平均持有 27 天——三成以上的单子既没打到止损也没到目标，白占 30 天仓位后在市价离场。
3. **形态差异巨大**：弱市回踩型 = 灾难（训练集 −3.26%/49 笔、验证集 −1.99%/42 笔，止损率 49–57%）。原因是回踩形态要求 MA20 ≥ MA60（上升趋势），在弱市里属于逆势接刀；而且 `raw_gate` 本就要求上证站上 20 日线，所以弱市回踩信号极少（样本不足）。
   弱市真正在跑的是**突破型**（−0.28% / +0.15%）。

## 3.5 把弱市拆成「牛市回调」与「熊市中继」（M1–M4）

假设：弱市（指数跌破 MA20）里，指数仍在 MA60 上方属于**牛市中的回调**，赔率应好于已在 MA60 下方的**熊市中继**。

| 方法 | 训练集 弱市 | 验证集 弱市 | 判定 |
|---|---|---|---|
| M1 弱市 + 指数在 MA60 上方 | **−0.98** / 52.6% / 557（t=−1.88） | **+0.85** / 59.4% / 867（t=2.08） | 符号翻转 |
| M2 弱市 + 指数在 MA60 下方 | +0.22 / 55.4% / 775（t=0.52） | −0.28 / 53.5% / 1085（t=−0.80） | 符号翻转 |
| M3 M1 + 只做突破 | −0.87 / 53.4% / 532（t=−1.61） | +0.74 / 59.0% / 857（t=1.80） | 符号翻转 |
| M4 M1 + 反转 | −0.88 / 44.4% / 1242（t=−3.86） | −0.06 / 47.7% / 1971（t=−0.35） | ✗ |

**这是本次研究最关键的一格**：M1 在验证集上是全部 29 个组合里**最好**的一格（+0.85%、胜率 59.4%、t=2.08），
在训练集里却是**最差**的一格（−0.98%、t=−1.88）；M2 恰好相反。也就是说，
"牛市回调可买、熊市中继不买"这个听起来非常合理、且在任一窗口都能自圆其说的结构性解释，
在另一段数据上**符号直接翻转**——它不是边缘，是噪声。

单看验证集就上线 M1，等于用 2020–2023 的规律去交易 2026 年的市场；单看训练集则会上线 M2。
两个窗口互相否决，正是双窗口协议存在的意义。

## 4. 强市候选方法（5 个）

| 方法 | 训练集 期望 / 胜率 / 笔数 | 验证集 期望 / 胜率 / 笔数 | 判定 |
|---|---|---|---|
| v12 现行（目标 +12%，到 +10% 减半，持有 30） | +1.57 / 61.0% / 2060 | +0.65 / 57.7% / 1976 | 基线 |
| S1 目标 +15% | **+1.91** / 60.0% / 1996 | +0.62 / 56.0% / 1910 | ✗ 验证集胜率 −1.7pp |
| S2 目标 +20% | +1.82 / 57.9% / 1912 | +0.60 / 53.9% / 1828 | ✗ 胜率 −3.8pp |
| S3 减半点 +8%、目标 +15% | +1.73 / 60.9% / 1996 | +0.58 / 57.3% / 1910 | ✗ |
| S4 持有 40 日 | +1.23 / 61.4% / 2002 | **+0.89** / 60.0% / 1921 | ✗ 训练集变差 |
| S5 ATR 移动止盈（2×ATR） | +1.23 / 56.0% / 2161 | +0.29 / 51.0% / 2065 | ✗ |

**强市这边最重要的发现**：目标 +15% 在近 3 年把期望从 +1.57% 拉到 +1.91%（t=7.27），但在 2019–2023 反而略差（+0.62% vs +0.65%，胜率 −1.7pp）。它赚的是 2024–2026 这段单边行情的钱，**不是可迁移的 edge**。若当初按训练集拍板上线，正好踩进过拟合陷阱。

## 5. 最终结论与处置

1. **不改线上规则**：弱市继续 0 仓位、目标继续 +12%、减半点 +10%、持有 30 日。
2. **"弱市不买"要保留，但理由要改**：不是为了躲负期望（弱市期望≈0，并不显著为负），而是为了**降低回撤与换手**——弱市子集的交易序列回撤 −886，弱市止损率 22.3% vs 强市 14.3%，且弱市信号占全部信号的 40–50%，一旦放开会把组合风险显著抬高。
3. **两个"看起来能上线"的候选都被反证**：
   - R2 反转（8/4/8/10）：验证集 +0.34%（t=2.30）过线，训练集 −0.19% → 放弃；
   - M1 弱市+指数在 MA60 上方：验证集 +0.85%（t=2.08，59.4%）是全表最好的一格，训练集 −0.98%（t=−1.88）是全表最差的一格 → 放弃。
   两个窗口互相否决，说明这些结构的**符号不稳定**，属噪声而非边缘。
4. **强市暂无可采纳的改进**：现有 +12% 目标在双窗口下是稳健的局部最优。

## 6. 方法论局限（诚实声明）

- **验证集在训练集之前**（按需求口径）：这检验的是"跨环境稳健性"，但 2026 年的市场更接近训练集那段，所以验证通过≠未来可用；两者的期望差异（+1.57 vs +0.65）本身就是环境差异的证据。
- **逐笔等权，不是组合**：没有槽位竞争、资金约束、同日多信号排序，因此会高估高频方法的收益（弱市方法动辄 2000–7000 笔）。
- **样本**：236 只、市值≥50 亿，存在市值/存活偏差；新股与退市股未纳入。
- **不含 AI 层**：只验证确定性骨架（入场形态 + 确认条件 + 机械止损/止盈），不含当日 AI 建议与否决。
- **多重比较**：共测 29 个组合（基线 1 + 弱市入场 18 + 闸门 5 + 强市 5），即使全为噪声，也会有个别组合偶然过线；任何单格 t≈2 的结果在 29 次比较下都应打折看待。

## 7. 下一步（按性价比排序）

1. **组合级复验**：把候选方法放进 `engine/portfolio_sim.py` 的 5 槽/5 万资金框架，看资金曲线与回撤，而不是逐笔期望。
2. **换 regime 定义**：MA60 + 市场宽度（涨跌家数/成交额）比双指数 MA20 更贴近"能不能做"；当前定义把 2024–2026 的浅回踩也判成弱市。
3. **扩大验证样本**：加入 2015–2019（含 2015 股灾与 2018 熊市），当前验证集只有 4 年。
4. **弱市工具化**：A 股弱市真正的正期望来源可能是空仓以外的**低相关资产/ETF 轮动**，而非个股择时——这属于新策略，不在本次范围。
