# 实施计划：AI 投资分析助手（invest-assistant）

| 项 | 值 |
|---|---|
| 版本 | v0.1 |
| 日期 | 2026-10-11 |
| 关联 | `docs/requirements.md` v0.2 ｜ `docs/design.md` v0.1 |
| 完成定义（DoD） | 批次 1/2/3 依次达成各自 DoD 并打里程碑 tag；所有任务测试通过、文档同步、可独立回滚 |
| 总预估 | 约 25 人日（参考值；业余开发以实际节奏为准） |

## 总体规则

- 每个任务 = 一个逻辑变更 = 一个 Conventional Commit；**不在同一任务里混合重构与功能**。
- 任务完成时必须「可独立验证」（测试通过/可演示），**主干始终保持可运行**。
- 测试与任务同提交；破坏性接口变更需同步更新关联模块与文档。
- 执行时用 todo 列表跟踪，完成一个勾一个。
