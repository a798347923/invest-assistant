# S1 数据源冒烟验证报告

| 项 | 值 |
|---|---|
| 日期 | 2026-10-11 |
| 环境 | Windows，Python 3.14.6，akshare 1.19.1，国内网络（无外网）；pip 镜像：华为云（清华镜像对 pip 返回 403） |
| 脚本 | `scripts/spike_datasource.py`（首轮 14 项）、`scripts/spike_datasource2.py`（定向复核 9 项） |
| 原始数据 | `docs/spike-datasource-raw.json`、`docs/spike-datasource-raw2.json` |

## 一、结论

1. **akshare 的东财 push2 / push2his 系接口在本机网络下稳定不可用**（RemoteDisconnected / 超时，复核重试后依旧失败）。受影响项：股票/ETF/指数日线、全市场快照、单只实时行情。
2. **自建直连适配器全部可用且快**：东财 push2 / push2his / clist（requests + 浏览器请求头）、新浪 hq 批量行情与 kline 日线。
3. **akshare 非东财源接口全部可用**：交易日历（新浪）、场外基金净值（天天基金）、新闻、公告（cninfo）、财务数据。
4. 天天基金 fundgz 盘中估值接口可用（157ms）。

## 三、对设计的影响（已回填 `docs/design.md` 6.1）

- 数据源分层调整为：**行情类（实时/日线/快照）→ 自建直连适配器为主（EastmoneyClient 主、SinaClient 备）；基金/资讯/财务/日历 → akshare**。
- 保留 Adapter 隔离与「数据源健康探测」：版本与网络环境变化可能改变结论，适配层需可随时切换数据源。
- 轮询性能预算确认：一批 100 只行情约 0.4s，单轮全持仓检查远低于 30s 目标。

## 四、遗留事项

- 财务数据的「公告日」（ann_date）字段可用性需在 B3-03（回测时点）前核实（本次仅验通接口，未验字段完整性）。
- 依赖版本锁定：`akshare==1.19.1` 写入项目依赖（B1-01 执行）。
- 本报告结论针对当前网络；若后续 akshare 东财接口恢复或不稳定，以适配层健康探测结果为准。

## 五、追加观察（2026-10-11 晚，S2 期间发现）

- `push2his.eastmoney.com`（历史K线）出现**间歇性连接重置**：同进程 3 次退避重试均失败；同一时刻 `push2.eastmoney.com`（实时）与新浪两个接口均正常。
- **实锤结论**：免费源存在按主机粒度的偶发故障 → 「重试退避 + 多源回落 + 健康探测」为**必需机制**。
- 日线实现规格确定为：先请求 EM（前复权）→ 失败回落新浪 kline（不复权，报告中标注局限）→ 两源均失败则显式标记「数据不可用」。
