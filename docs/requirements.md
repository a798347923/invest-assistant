# 需求文档：AI 投资分析助手

| 项 | 值 |
|---|---|
| 项目名 | invest-assistant（AI 投资分析助手） |
| 版本 | v0.2（定稿候选） |
| 日期 | 2026-10-11 |
| 状态 | 待最终确认 |
| 定位 | 个人自用工具（单用户） |

## 0. 一句话定位

面向个人的本地化投资纪律系统：量化初筛 + LLM 深度分析解决「买什么」；强制退出规则 + 盘中监控提醒解决「获利回吐」；规则级回测验证方法有效性。

## 1. 背景与目标

**问题**：
1. 不知如何选股/选基；
2. 获利后未及时卖出，回吐甚至亏损；
3. 信息分散、盯盘占精力。

**目标**：选股有据可依；卖出有纪律可依；提醒及时可靠。

**成功指标**（过程指标，不做收益承诺）：
- 触发条件命中后，电脑在线时 ≤15 分钟内送达提醒
- 100% 的买入记录携带完整退出规则（强制录入保证）
- 每条提醒可追溯：触发原因、当时价格、LLM 解读
- 回测：任一「初筛模板 + 退出规则」可在指定区间产出日线级报告

## 2. 目标用户与场景

唯一用户：本人。
场景：买入时快速录入 → 盘中看提醒 → 收盘看体检报告 → 周末看候选池与复盘。

## 3. 已确认的关键决策

| 维度 | 决策 |
|---|---|
| 品种 | A股股票、场内 ETF/LOF、场外基金 |
| 策略 | 价值、成长、波段、定投；每笔绑定策略，退出规则差异化 |
| 形态 | 本地 Web 面板 + 后台常驻服务 |
| 部署 | 个人电脑（Windows）常开；开机自启 + 崩溃自动重启 |
| 监控 | 盘中定时轮询（默认 10 分钟）+ 收盘深度分析 |
| 提醒 | 邮件 + 微信（Server酱/PushPlus）双通道；触发即时逐条 + 收盘汇总 |
| 提醒内容 | 触发即带 AI 解读（发生了什么 + 当前盈亏 + 建议动作选项） |
| 持仓 | 手动录入；强制退出规则；分红摊薄成本、拆股手动修正 |
| 选股 | 全市场量化初筛（默认 10 只/天，可配）+ 自选精析 |
| 回测 | 一期支持；仅规则级（不含 LLM）；标准口径（日线、计费、含移动止盈） |
| LLM | DeepSeek 默认；OpenAI 兼容接口，可切换 |
| LLM 成本 | 不设硬性上限；用量看板 + 软阈值提示（只提示不降级）；保留去抖与当日缓存 |
| 数据源 | 免费优先（AkShare 等），容错重试，失败显式标注 |
| 访问控制 | Web 面板默认仅本机（127.0.0.1），可选密码 |
| 技术栈 | Python（设计阶段细化） |

## 4. 功能需求（用户故事 + 验收标准）

### M1 持仓与交易管理

**US-1.1 录入买入（强制退出规则）**
字段：标的、类型、数量、成本价、日期、策略标签、止盈线、止损线（或移动止盈回撤%）、最长持有期。
- AC1：Given 表单未填任一退出规则字段，When 保存，Then 拒绝保存并明确指出缺失项
- AC2：Given 完整表单，When 保存，Then 持仓列表即时显示，退出规则立即进入监控
- AC3：场外基金录入时字段按净值/份额适配（无盘中触发概念，用净值触发）

**US-1.2 卖出记录**：支持全部/部分卖出，自动结算已实现盈亏。

**US-1.3 持仓总览**：市值、成本、浮动盈亏、盈亏%、持有天数、策略、各退出规则当前状态（距触发多远）。

**US-1.4 修正/删除**：误录入可修正，操作留痕。

**US-1.5 分红与拆股**：分红现金流录入并自动摊薄成本；拆股提供手动修正入口（数量/成本价）。

### M2 市场数据接入

**US-2.1 自动拉取**：A股/ETF 行情（含延迟实时）、基金净值与盘中估值、财务指标、公告、新闻、交易日历。
- AC1：数据源失败自动重试；仍失败则显式标记「数据不可用」，不得静默使用过期数据
- AC2：所有分析与提醒附带数据时间戳
- AC3：非交易日/节假日不触发行情类监控

### M3 选股与分析

**US-3.1 全市场量化初筛**：按模板（价值/成长/趋势）每日筛出候选池（默认 10 只/天，可配）。
- AC：每个候选附「入选理由」（命中哪些条件）；筛选条件可视化可调

**US-3.2 LLM 深度分析卡**（候选池 + 自选 + 持仓）
内容：基本面、技术面、估值分位、新闻/公告解读、多空因素、风险提示。
- AC1：引用的事实均带来源与时间戳；无来源的推论明确标注「模型推断」
- AC2：每张卡含免责声明；结果入库，可回看历史分析
- AC3：单标的有耗时与成本上限；失败可重试或降级为「仅数据摘要」
- AC4：触发解读复用当日分析卡数据（缓存），同一标的当日不重复全量分析

**US-3.3 自选池管理**：增删、分组、备注。

### M4 监控与提醒（核心）

**US-4.1 盘中轮询监控**：触发条件 = 止盈线 / 止损线 / 移动止盈回撤 / 涨跌幅异动（可扩展指标条件）。
- AC1：轮询周期可配（默认 10 分钟）；单轮全持仓检查为纯本地规则判断，**不调用 LLM**，< 30 秒
- AC2：同一持仓同一条件在未复位前只提醒一次；条件解除后可再次触发；每日推送有条数上限
- AC3：涨跌停无法成交时，提醒照发但标注「当前可能无法成交」

**US-4.2 触发解读（触发即带 AI）**：命中的提醒即时附带 LLM 生成的「发生了什么 + 当前盈亏 + 建议动作选项（卖出 / 继续持有观察 / 复核退出规则）」。

**US-4.3 收盘纪律体检**：收盘后对全部持仓输出体检报告：接近触发的、需次日行动的、已触发的执行情况；附次日操作建议清单。

**US-4.4 双通道通知与推送节奏**：邮件 + 微信并行；单通道失败自动重试；双通道均失败记录并在面板醒目提示。节奏：触发即时逐条（去抖后）+ 收盘汇总一条。

**US-4.5 补报机制**（应对电脑关机/休眠）：服务恢复后检查未送达提醒并补发，标注「延迟补报」；超时效的标注「已过期，请复核」而非省略。

**US-4.6 提醒历史与执行标记**：提醒可标记「已处理/已忽略/已过期」；数据用于复盘统计「提醒了但没执行」。

### M5 回测（一期，规则级）

**US-5.1 回测「初筛模板 + 退出规则」**
- 范围：量化初筛 + 退出规则（固定止盈止损 + 移动止盈）；日线级；不含 LLM
- 输入：历史区间、初筛模板、退出规则参数
- 输出：年化收益、最大回撤、胜率、平均持有期分布，对比基准（沪深300 / 中证500）
- AC1：严格使用带时间戳的历史数据，杜绝未来函数；报告列出假设与局限（幸存者偏差、免费数据覆盖）
- AC2：计入费用，默认值可配：佣金万 2.5、印花税卖出 0.05%、滑点 0.1%；股票/ETF/基金费率模板区分
- AC3：明确说明 LLM 不参与回测及原因（成本与后视污染）

### M6 复盘报告

**US-6.1 周报**：持仓变化、盈亏、提醒触发/执行统计、「错过的卖点」（事后回看：若当时按规则卖出会如何）。

### M7 Web 面板

**US-7.1 页面**：总览 / 持仓 / 候选池 / 分析卡 / 提醒历史 / 回测 / 设置。
- AC1：默认仅本机访问（127.0.0.1）
- AC2：可选密码（设置中开启）

### M8 设置与配置

**US-8.1 配置**：LLM、数据源、通知渠道、监控参数；策略档案模板（每种策略的默认退出规则，录买入时一键套用）。
**US-8.2 免责声明**：首次启动与设置页展示风险提示与免责声明。
**US-8.3 用量看板**：当日/近 7 日 token 用量与花费；软阈值超出仅提示，不降级。

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 可靠性 | Windows 开机自启 + 崩溃自动重启；补报机制（US-4.5） |
| 性能 | 盘中例行轮询（纯本地规则）单轮 < 30s；LLM 分析异步，不阻塞监控 |
| 成本 | 不设硬性上限；用量看板 + 软阈值提示；保留去抖与当日缓存 |
| 安全 | API Key/邮箱授权码等仅存本地配置文件（不进版本库）；面板默认不暴露公网 |
| 合规 | 内置免责声明；不做收益承诺；不做自动交易；遵守数据源使用条款 |
| 兼容 | Windows 10/11；Python 3.11+（设计阶段确认） |

## 6. 关键边界与例外

数据源故障/限流；电脑休眠关机（补报）；涨跌停（标注）；停牌/退市/基金清盘（暂停监控并标记）；场外基金净值延迟（T+1，盘中估值仅供参考）；节假日；分红拆股（已定方案：分红摊薄成本、拆股手动修正）；LLM 幻觉（强制数据 grounding + 免责）。
